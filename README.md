# cave_escape

A web games built using flutter.
Game Name : Cave Escape 
Genre Interactive : Text-Based Adventure

## Introduce

Cavee Escape is a node-based story game where the player explores a mysterious cave after falling in. 

The objective is the player need to escape from the cave by making the correct choice at each node. 

The games also includes the best completion time system to challenge players to escape as efficiently as possible. 

## Getting Started

**Prerequisites**
Flutter SDK (>= 3.x)
Dart SDK
web

### Installation

```
git clone https://github.com/meYeeMing/cave_escape.git
cd cave-adventure
flutter pub get
```

Running the application under the web
```
flutter run -d chrome
```

## Configuration 
To add more story node or update the existing the node,  user need update the `/assets/story.json` for the story and the story choice and `/assets/image_list.json` for the image id. 

All the images are in `.webp` format with a resolution of 1024 x 1536.
